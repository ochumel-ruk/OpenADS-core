# OpenADS-core

Открытое исследование высокоэффективного линейного ускорителя на обратной волне (BWLAP) для подкритических ядерных систем (ADS).

## Цель проекта
Проверить и воспроизвести ключевые элементы технологии Б. и О. — медной ускоряющей структуры на обратной волне, способной работать при комнатной температуре с высоким КПД. Доказать или опровергнуть возможность создания компактного и дешёвого драйвера для трансмутации ядерных отходов и чистой энергетики на уране-238 и тории-232.

## Почему это важно
Современные проекты ADS упираются в стоимость и ненадёжность сверхпроводящих ускорителей. УЛОВ обещает решить эту проблему, сделав чистую ядерную энергию доступной.

## Текущий статус
- **Этап 0:** Развёртывание инфраструктуры, сбор исходных данных.
- **Этап 1 (в процессе):** Цифровое моделирование одной ускоряющей ячейки.
